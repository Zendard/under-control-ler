# Under Control(ler)
Share gamepad inputs peer-to-peer
# Compatibility
## Hosting
- Hosting on linux should just work (try running as root if it doesn't)
- Hosting on windows requires [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0)
## Joining
- I only own an Xbox one gamepad but all gamepads supporting WGI on windows and evdev on linux should work
- Use [DS4Windows](https://github.com/Ryochan7/DS4Windows/releases) for Playstation controllers if they don't work
